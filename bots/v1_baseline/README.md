# V1 Baseline Folder

This folder is a frozen `chess-bench-v1` bot snapshot for the local baseline bot.

Files:

- `bot.json`: manifest read by the benchmark UI
- `v1_baseline`: fixed executable snapshot of the current bot logic
- `run.sh`: launches the frozen `v1_baseline` binary

Future changes in the repo `src/` folder do not affect this bot unless you rebuild and replace `v1_baseline` manually.
